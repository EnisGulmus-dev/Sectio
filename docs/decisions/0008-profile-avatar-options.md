# Profil avatar seçenekleri

İletişim altyapısı planına ek: profil görünümünde kullanıcı isim baş harfini,
yüklediği profil fotoğrafını veya hazır avatar seçebilir. Sağlanan on PNG proje
içindeki `frontend/public/avatars` dizinine kopyalandı. Seçim arayüzü görselleri
Erkek ve Kadın gruplarında gösterir; gruplama kullanıcı hesabında cinsiyet alanı
oluşturmaz veya hangi gruptan seçim yapılacağını kısıtlamaz. Görseller CSS ile
daire içinde kırpılır, kaynak PNG'ler değiştirilmez.

Durum: Görseller, katalog ve seçim bileşeni hazırlandı. Profil sayfasına bağlantı,
kalıcı seçim, fotoğraf yükleme, hesap silme/temizlik ve sohbet arayüzünde avatarın
kullanılması henüz yapılmadı. Bunlar mevcut profil ve kanal işiyle birlikte
tamamlanacaktır. Varsayılan görünüm isim baş harfidir.
